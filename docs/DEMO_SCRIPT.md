# Сценарий показа Aperture

Показ соединяет старый Gemini AI Sentinel с новой оболочкой: проверка Python-кода и запуск Python-задачи происходят в одном Compute Studio, а оба действия проходят через gateway с отдельными лимитами и подтверждениями владельца.

## Подготовка

Укажи ключ Google AI Studio в PowerShell и запусти объединённый preview:

```powershell
$env:GEMINI_API_KEY = '<Google AI Studio API key>'
.\start_preview.bat
```

Открой `http://127.0.0.1:3000/#studio`, выбери **Temporary key** и дождись реального статуса gateway и работников. Gemini получает запрос после подписи; Google может отдельно тарифицировать API. Preview показывает реальную модельную генерацию через Gemini API и Python-вычисление в `OFF_CHAIN`, без Solana-платежа.

## Трёхминутный сценарий

### 0:00–0:20 · Единое рабочее место

Покажи Overview и три типа задач: модельный запрос, Python-код и agent workflow. Объясни, что все они используют общий gateway, а каждая задача ограничивается до запуска.

**Текст:** «Aperture соединяет Gemini AI Sentinel из старого проекта с новым рынком AI и compute. Здесь можно проверить Python-код моделью, затем отдельно проверить политику исполнения, цену и лимиты перед запуском».

### 0:20–0:40 · Worker network

Покажи реальные heartbeat CPU-worker и настроенные model offers. Назови только значения, которые вернул текущий gateway; если он недоступен, не подставляй примерные числа.

**Текст:** «Модель и compute подключаются через один gateway. Сейчас offers задаёт оператор; открытый permissionless-каталог и автоматические выплаты поставщикам ещё не реализованы».

### 0:40–1:55 · Gemini AI Sentinel → Python compute

В Compute Studio оставь открытым Python source и выбери **Request AI Sentinel code review**. Справа откроется review drawer, а редактор останется виден. Проверь точный prompt, Gemini, бюджет и время, подпиши запрос и дождись ответа. Покажи receipt и advisory-отчёт, затем выбери **Close review and return to source**. Для совпадающего отчёта выбери **Review compute price & limits** и покажи отдельную compute quote и отдельную подпись перед исполнением.

**Текст:** «Старый Sentinel теперь не запускает и не одобряет код. Он отправляет исходник Gemini как недоверенный текст и возвращает advisory-ответ с квитанцией. Затем gateway независимо проверяет source policy и готовит отдельную цену; Python запускается только после второго подтверждения владельца».

### 1:55–2:30 · Agent workflow

Открой Workflows и покажи план, входные файлы, подтверждения шагов и сохранённое состояние восстановления.

**Текст:** «Та же оболочка ведёт и многошаговые data-задачи. Каждый шаг имеет свой source, входные данные и лимит; принятый gateway task можно восстановить без слепого повторного запуска».

### 2:30–3:00 · Граница доказательств

Покажи статус `OFF_CHAIN` и подписи/хеши в receipt.

**Текст:** «Квитанция связывает подписи, ограничения и байты результата с задачей, но сама по себе не доказывает правильность удалённого вычисления или модели. Этот preview выполняет настоящую работу без Solana-платежа. Devnet settlement требует настроенной программы и пополненного канала».

## Не заявлять по результатам этого показа

- GPU execution, permissionless provider marketplace или автоматические выплаты поставщикам.
- Платёж Solana, если receipt показывает `OFF_CHAIN`.
- Что ответ Gemini одобряет или гарантирует безопасность Python-кода.
- Что подпись доказывает качество ответа или faithful execution worker.
- Что обзорный protocol tour сам запускает задания: он объясняет этапы и показывает live-состояние gateway.
